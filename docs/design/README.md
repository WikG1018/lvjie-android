# 旅界 · 安卓原生版设计规划

浏览器打开 `index.html` 即可预览完整设计规范。

## 内容结构（层级 / 分类）

| 分部 | 内容 |
|------|------|
| A 设计基础 | 总览、原则、色彩系统（四级分类）、MiSans 字阶、形状间距海拔 |
| B 信息架构 | 导航层级树、核心任务流 |
| C 组件库 | 导航 / 动作 / 表单 / 反馈 / 数据展示 / 浮层，六类分表 |
| D 页面详解 | P01–P14 每页：目标 · 布局层级 · 元素规格 · 状态变体 · 要点 · mockup |
| E 系统规范 | 状态异常、动效触感、技术架构、路线图、独立项目策略 |

## 字体

Web 预览使用 CDN `misans@5.0.0`（MiSans Regular/Medium/Semibold/Bold）。
安卓工程请将 MiSans 打进 `res/font/`。

## 世界观主题

顶部可切换修仙 / 玄幻 / 武侠 / 职场 / 末世 / 西幻，全部 mockup 联动换肤。

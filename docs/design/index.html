A1 — PRINCIPLES

设计原则

四条原则贯穿所有界面决策，冲突时按序取舍。

P1

叙事优先，数据退后

主场景永远最大面积留给故事。数值、进度、货币收进状态胶囊与底部抽屉，不与剧情争夺注意力。

P2

一世界一皮肤

每套世界观自带色彩、文案词表、升级动词。进入世界即整机换肤；回到列表恢复中性系统色。

P3

单手热区操作

高频动作（行动、发送、选项、突破）落在拇指热区。顶栏只放状态与低频入口；危险操作进确认层。

P4

状态即反馈

AI 流式生成、数值变化、突破成功、任务达成——每个状态变化都有触感、微动效或 SnackBar，不静默失败。

A2 — COLOR SYSTEM

色彩系统

按「中性骨架 / 品牌强调 / 功能语义 / 世界观主题」四级分类。世界主题只替换强调色系，骨架保持一致。

六套世界观强调色

点顶部主题条可实时预览。每套包含 accent / soft / deep / glow，映射 Material 3 的 primary / primaryContainer / onPrimaryContainer / elevation overlay。

世界观词表（文案随皮肤切换）

等级、进度、货币、升级动词全部来自世界包 lexicon，客户端不硬编码。

A3 — TYPOGRAPHY

字体排印 · MiSans

正文与标题统一 MiSans（本地字体资源 + Web 预览同源）。剧情正文可选衬线增强「在读故事」感；数值启用等宽数字。

字阶标本

使用规则

Aa
单一字族
MiSans 全局；不混用第三方中文字体。字重只用 400 / 500 / 700（Semibold 650 用于强调）。
12
等宽数字
战力、货币、进度等数值启用 tabular-nums，保证列表右对齐扫读。
¶
剧情衬线
事件叙事正文可用 Noto Serif SC / 思源宋体；UI chrome 永远无衬线。
↔
可缩放
跟随系统字体缩放到 1.3× 时禁止截断；卡片高度允许增高。
